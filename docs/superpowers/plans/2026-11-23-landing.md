# fuxx landing site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A prerendered, fully animated landing page for fuxx at `https://fuxx.fitzfitz.site` that turns
agent-running devs into downloads and GitHub stars, covering every fuxx v0.12.6 capability.

**Architecture:** TanStack Start (React) on Vite 8 with `@cloudflare/vite-plugin`, prerendering `/` to static HTML
and serving it from a Cloudflare Worker. Page content (inventory, chapters, grid cards) lives in typed data
modules that a coverage test checks against the capability inventory. The hero's three.js scene is a lazily
loaded chunk with a static SVG fallback; scroll choreography is GSAP ScrollTrigger inside `gsap.matchMedia`.

**Tech Stack:** pnpm · Node 26 · TypeScript 7.0 · Vite 8.3 · React 19.3 · @tanstack/react-start 1.169 ·
@cloudflare/vite-plugin 1.70 · wrangler 4.166 · gsap 3.15 + @gsap/react 2.1 · three 0.187 (plain, no R3F) ·
sharp 0.35 (screenshot conversion) · vitest 5.1 (+ jsdom, @testing-library/react).
Versions checked with `npm view` on 2026-11-23; re-check with Context7 / npm before installing.

**Spec:** `docs/superpowers/specs/2026-11-23-landing-design.md` — read it first; this plan argues from it.

## Global Constraints

- Two goals only: **Download for macOS** and **★ Star on GitHub**; both in the sticky header, hero, and close.
- Anti-goal 1: no stutter — 60 fps on a base Apple Silicon MacBook Air; one WebGL canvas; render loop pauses
  off-screen / tab hidden; `devicePixelRatio` capped at 1.75; GSAP animates transform/opacity only;
  Lighthouse mobile performance ≥ 90.
- Anti-goal 2: never generic AI startup — no purple/blue gradients, glassmorphism, blobs, ✨ icons,
  "10x" copy. Near-black, neon green ╭∩╮, mono type, keycaps, README voice. Only extra colours: status colours.
- Status colours = Catppuccin Mocha values from fuxx-cli `src/theme.rs` (copy exact hex in Task 1).
- Every claim on the page must come from the spec's capability inventory; nothing beyond it.
- `prefers-reduced-motion: reduce` → static hero, no pinning, chapters stacked, replays show final state.
- Phones (< 768px): chapters stacked, lighter hero, no horizontal scroll at 375px.
- Screenshots: ui-shots dark renders only, AVIF + WebP, ≤ 2× display width, **≤ 120 KB per file**, modest
  display size inside a fuxx window frame, explicit width/height, lazy except the first story frame.
- Do **not** use the `preferences-plugins` ui-shots renders (fake plugins); the plugins visual is an HTML mock.
- Public repo: no work-project names, no personal paths (`/Users/…`) in any file or image.
- No Co-Authored-By or other AI attribution in commits. Build output only inside this repo.
- fuxx-cli is read-only for this work, except running its `scripts/ui-shots.sh --png` (then its
  `scripts/prune-target.sh`). Never run a command named `fuxx`.
- Pushing: commit locally; **one push at the end**, after the privacy grep and after the user has seen the
  deployed site.

## Review Focus

1. **GitHub API down / rate-limited at build** → Download falls back to
   `https://github.com/fitzfitz/fuxx-cli/releases/latest`, build still succeeds (test in Task 1).
2. **Star count fetch fails or `sessionStorage` throws** (private window) → star button renders without a
   number, no console error (test in Task 3).
3. **WebGL unavailable** (context creation fails, old GPU) → static SVG neon hero stays, no thrown error
   (test in Task 3).
4. **Reduced motion** → no ScrollTrigger pin is created; typed replays render their final text immediately
   (tests in Task 4).
5. **Clipboard API denied** on copy buttons → button shows "press ⌘C" state, no unhandled rejection
   (test in Task 5).
